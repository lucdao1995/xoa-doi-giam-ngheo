# Prompt Template: Dịch chương truyện

Khi cần dịch một chương mới, dùng prompt-master với thông số sau:

## Target tool
Claude

## Project context
Truyện "Xoá đói giảm nghèo" (tác giả Ngụy Ám Thời Khắc).
Thể loại: Ngôn tình, Cấm kỵ, Niên thượng (cha chồng - con dâu), HE.
Bối cảnh: Thôn quê Trung Quốc, công tác xóa đói giảm nghèo.

## Style requirements
- Từ vựng: xem file `translation-style-guide.md`
- Xưng hô: Chu Đình → "hắn", Tô Mạn → "cô", Chu Viễn → "nó"
- Câu dài 200-400 ký tự, ghép mệnh đề bằng dấu phẩy
- Miêu tả cảm giác: xúc giác (nóng/lạnh/đau), khứu giác (mùi)
- Giọng văn tối tăm, cấm kỵ, thuần Việt
- Output: markdown, mỗi đoạn cách nhau blank line
